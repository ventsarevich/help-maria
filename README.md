# Статический анализ DJI-видео

Проект извлекает кадры из всех видео в `videos` и анализирует каждый кадр независимо. Соседние кадры, движение дрона и оценка движения объектов не используются.

## 1. Запуск анализа

Дважды нажмите `static_analyze.command`, затем выберите:

- вариант: обычный или тройной анализ;
- модель: YOLOE или Grounding DINO;
- конфигурацию объектов;
- глубину анализа.

Рекомендуемый первый прогон: YOLOE → `full_search` → `balanced`. Профиль проверяет статический кадр каждые 3 секунды и использует увеличенные фрагменты кадра.

Вариант `Тройной` запускает на каждой статической плитке YOLOE, Grounding DINO и SigLIP. Первые две модели рисуют рамки, а SigLIP оценивает плитку целиком по тексту. Совпадение нескольких анализаторов получает более высокий рейтинг; в HTML указано, какие модели поддержали кандидата. Этот режим существенно медленнее.

Коэффициенты анализаторов хранятся в `analyzer_weights.json`. Для каждого кандидата в JSON/CSV сохраняются исходные confidence отдельных моделей и итоговый взвешенный confidence. Отчёт по умолчанию показывает самые сильные совпадения первыми; сортировку можно переключить на согласие моделей или таймкод.

Каждый запуск создаёт отдельную папку в `results`. В ней находятся полный HTML-отчёт, кадры с разметкой, исходные фрагменты, CSV/JSON и настройки запуска.

## 2. Просмотр результатов

Откройте `report.html` внутри последней папки в `results`. Результаты сгруппированы по видео. В просмотрщике:

- `←` и `→` переключают кандидатов;
- колесо мыши или `+`/`-` изменяют масштаб;
- изображение можно перетаскивать;
- `Esc` возвращает к тому же месту отчёта.

Чтобы улучшать отдельные картинки прямо по клику, запускайте отчёт через `open_report.command`. Кнопка `✨ Улучшить` отправит только текущий фрагмент в локальную Swin2SR-модель, дождётся результата и сразу покажет его. Окно запуска должно оставаться открытым.

## 3. AI-улучшение найденных фрагментов

После анализа дважды нажмите `enhance.command`. Swin2SR восстановит фрагменты последнего запуска, увеличит их разрешение в 2 раза и обновит HTML. В просмотрщике станет доступна кнопка `✨ Улучшить`.

Исходное изображение всегда нужно использовать для проверки: super-resolution может создавать правдоподобные мелкие детали, которых нельзя достоверно подтвердить по исходному кадру.

## Конфигурации

Готовые списки объектов находятся в `configurations.json`:

- `person_only`;
- `people`;
- `clothing`;
- `equipment`;
- `full_search`.

Повторяемый запуск без меню:

```bash
.venv/bin/python batch_analyze.py --engine yoloe --config full_search --profile balanced
```

AI-улучшение только 100 лучших кандидатов:

```bash
.venv/bin/python ai_enhance.py --limit 100
```
